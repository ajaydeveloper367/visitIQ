# 🏥 VisitIQ - Healthcare Visit Prioritization System (v2.0.0)

**AI-powered healthcare scheduling with FHIR compliance and smart patient prioritization.**

> Current version: 2.0.0

## 🚀 **Quick Install**

### **Local Installation (Recommended)**
```bash
./setup-local.sh
```

### **Docker Installation**
```bash
./setup-docker.sh
```

### **After Installation**
1. Generate data: `~/.visitiq/visitiq generate-data`
2. Start system: `~/.visitiq/visitiq start` 
3. Open: http://localhost:8501
